# HTML Resume
This project is a simple resume created using HTML.  
It showcases personal details, education, skills, and contact information in a clean layout.

## Features
- Structured resume using semantic HTML
- Easy to read and modify
- Beginner-friendly project

## Technologies Used
- HTML5

## How to Run
1. Clone or download the repository
2. Open `index.html` in any web browser

## Project Purpose
This project was created to practice HTML basics such as tags, elements, headings, lists, and links.
